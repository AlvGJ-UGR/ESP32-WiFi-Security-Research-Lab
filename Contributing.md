# Contributing

This is a personal educational project, but structured feedback and suggestions are welcome.

## Scope

This repository is strictly limited to **passive analysis, educational tooling, and documentation**. Contributions that add offensive capabilities, active injection, deauthentication attacks, or any feature that could be used to disrupt networks will not be accepted regardless of framing.

## How to Contribute

### Reporting a Bug

Use the Bug Report issue template. Include:
- Python version and OS
- The exact command you ran
- The full error output
- A sample of the input file (anonymised if needed)

### Suggesting a Feature

Use the Feature Request issue template. Describe:
- What problem it solves
- How it fits the educational scope of the project
- Whether you plan to implement it yourself

### Submitting a Pull Request

1. Fork the repository
2. Create a branch: `git checkout -b feature/your-feature-name`
3. Make your changes with clear, descriptive commits
4. Ensure your code runs without errors on Python 3.10+
5. Open a pull request with a description of what changed and why

## Code Style

- Python 3.10+ with type hints where practical
- No external dependencies unless strictly necessary — this project is intentionally stdlib-only
- Docstrings on all public functions and classes
- Descriptive variable names over brevity

## Legal Reminder

By contributing you confirm that your contribution is intended for educational use only and does not facilitate unauthorized access to networks or systems.
